# Architecture decisions

Each file records one decision: the context that called for it, what was decided, the alternatives when there were real ones, and what it costs. The format follows Michael Nygard's architecture decision records.

A new decision gets the next number. An accepted decision isn't rewritten when it changes: a new record replaces it, and the old one's status becomes "superseded by" the new one.
